恐怖の館

個人制作 / 制作期間：2週間

スクリプト構成・処理内容

  • StageGenerator.cs
    Tilemapを使用してマップを自動生成。
    壁・床・通路をランダム配置し、 必ずゴールへ到達可能な構造になるよう制御。
  • AStarPathFinder.cs
    グリッドベースのA*アルゴリズムを実装。
    障害物ノードを除外し、最短経路を探索。
  • EnemyController.cs
    一定間隔で経路再計算を行い、 プレイヤーの位置変化に追従。
    毎フレーム計算を避け、処理負荷を軽減。

工夫した点

  • マップ生成後に「到達不可エリア」を検出し再生成
  • 経路探索を一定時間ごとに制限しパフォーマンスを安定化
  • エネミーが引っかからないようノード補正処理を追加

エネミーAI 試作

スクリプト構成・処理内容

  • EnemyStateMachine.cs
    Idle / Chase / Pull / Cooldown / Return の 状態遷移を管理するステートマシン構造。
  • EnemySight.cs
    頭・胴・足元の3点からRaycastを発射し、 遮蔽物を考慮した視線判定を実装。
  • EnemyPull.cs
    プレイヤーを引き寄せる攻撃処理。
    距離制限・硬直時間・クールダウンを管理。

設計で意識した点

  • 1スクリプト1責任を意識した分割設計
  • Update依存を避け、一定間隔で判定処理を実行
  • 状態遷移時に不要な処理を即停止する安全設計
